Ý tưởng cốt lõi

Trong mỗi bước, tìm phần tử nhỏ nhất trong đoạn chưa sắp xếp và đưa nó về đúng vị trí đầu đoạn đó.

02

Số lần đổi chỗ tối đa

Chỉ n − 1 lần

✓ Phù hợp khi nào?

  • Mảng nhỏ (n < 50)
  • Chi phí ghi nhớ cao (swap đắt)
  • Cần thuật toán đơn giản để giảng dạy
  • Không quan tâm tính ổn định

✗ Không phù hợp khi?

  • Dữ liệu lớn (n > 10.000)
  • Cần sắp xếp ổn định
  • Dữ liệu gần như đã sắp
  • Yêu cầu hiệu suất cao
02

Thuật toán chi tiết

1

Khởi tạo

i = 0

2

Giả sử min

Gán min = i (a[i] là nhỏ nhất tạm thời)

3

Duyệt tìm min

Duyệt j từ i+1 đến n−1
Nếu a[j] < a[min] → cập nhật min = j

4

Đổi chỗ

Đổi chỗ a[i] ↔ a[min]

5

Tăng i

Tăng i lên 1, quay lại bước 2 nếu i < n−1

6

Kết thúc

Mảng đã sắp xếp tăng dần

Lưu ý: Vòng ngoài chạy đúng n−1 lần, vòng trong giảm dần.

03

Độ phức tạp

⏱

Thời gian

O(n²)
  • Tốt nhất: O(n²)
  • Trung bình: O(n²)
  • Xấu nhất: O(n²)

Luôn so sánh đủ ≈ n(n−1)/2 lần

💾

Không gian

O(1)
  • Sắp xếp tại chỗ (in-place)
  • Chỉ cần biến tạm để đổi chỗ
⚖

Ổn định

Không
  • Không ổn định (unstable)
  • Có thể đảo vị trí các phần tử bằng nhau

Mã giả & Cài đặt C++

procedure SelectionSort(a[0..n−1])
  for i ← 0 to n−2 do
    min ← i
    for j ← i+1 to n−1 do
      if a[j] < a[min] then
        min ← j
      end if
    end for
    swap a[i] with a[min]
  end for
end procedure
void selectionSort(int a[], int n) {
  for (int i = 0; i < n - 1; i++) {
    int min = i;
    for (int j = i + 1; j < n; j++) {
      if (a[j] < a[min])
        min = j;
    }
    // Đổi chỗ a[i] và a[min]
    int temp = a[i];
    a[i] = a[min];
    a[min] = temp;
  }
}
Vòng for ngoài (i): chạy n−1 lần – mỗi lần cố định 1 vị trí
Biến min: lưu chỉ số phần tử nhỏ nhất tìm được trong đoạn
Vòng for trong (j): tìm phần tử nhỏ hơn a[min]
Đổi chỗ: chỉ thực hiện 1 lần sau khi tìm xong min

07

Ưu & Nhược điểm

Ưu điểm

  • Dễ hiểu, dễ cài đặt – phù hợp giảng dạy thuật toán cơ bản
  • Số lần đổi chỗ rất ít (tối đa n−1 lần) → tốt khi swap tốn kém
  • Không cần bộ nhớ phụ (in-place) → O(1) không gian
  • Hành vi dự đoán được: luôn chạy đúng số lần so sánh cố định
  • Không phụ thuộc vào dữ liệu đầu vào

Nhược điểm

  • Độ phức tạp O(n²) – chậm với dữ liệu lớn
  • Không ổn định (unstable) – có thể đảo vị trí phần tử bằng nhau
  • Luôn thực hiện đủ số lần so sánh, không tận dụng dữ liệu gần đúng
  • Không có cơ chế dừng sớm như Bubble Sort tối ưu
  • Ít được dùng trong thư viện chuẩn

Kết luận

Selection Sort là thuật toán sắp xếp đơn giản, dễ hiểu.

✓

Ưu điểm nổi bật: số lần đổi chỗ ít, không cần bộ nhớ phụ.

✗

Nhược điểm: chậm O(n²), không ổn định.

→

Phù hợp để học thuật toán cơ bản và áp dụng với dữ liệu nhỏ.

★

Trong thực tế, nên dùng các thuật toán hiệu quả hơn (Quick, Merge, Heap).
