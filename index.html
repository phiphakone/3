Selection Sort (Sắp xếp chọn)

Bài thuyết trình nhóm

Từ ý tưởng

Mỗi bước ta tìm phần tử nhỏ nhất trong đoạn chưa sắp, rồi đưa về đúng vị trí đầu của đoạn đó.

Hình dung xếp hàng theo chiều cao: chọn người thấp nhất đưa lên đầu, rồi chọn người thấp nhất trong số còn lại. Số lần đổi chỗ tối đa chỉ n trừ 1 lần.

Khi nào nên dùng / không nên dùng

Phù hợp khi mảng nhỏ dưới 50 phần tử, khi chi phí đổi chỗ rất cao, hoặc khi giảng dạy thuật toán cơ bản.

Không nên dùng dữ liệu lớn vì luôn O(n²). Một trăm phần tử khoảng mười nghìn lần so sánh. Mười nghìn phần tử khoảng một trăm triệu lần. Cũng không ổn định.

✓ Phù hợp khi

  • Mảng nhỏ (n < 50)
  • Chi phí swap cao
  • Giảng dạy cơ bản

✗ Không phù hợp khi

  • Dữ liệu lớn
  • Cần ổn định

Thuật toán chi tiết

Bước 1: khởi tạo i bằng 0.

Bước 2: gán min bằng i, tạm coi a của i là nhỏ nhất.

Bước 3: duyệt j từ i cộng 1 đến n trừ 1. Gặp phần tử nhỏ hơn thì cập nhật min.

Bước 4: đổi chỗ a của i với a của min. Sau đó tăng i, lặp đến khi i bằng n trừ 2.

Sơ đồ minh họa từng bước

Ví dụ mảng 64, 25, 12, 22, 11.

Tìm min bằng 11, đổi với 64. Tiếp theo min bằng 12. Rồi min bằng 22. Cuối cùng 11, 12, 22, 25, 64.

Ban đầu

Mã giả & Cài đặt C++

Vòng ngoài cố định từng vị trí. Vòng trong tìm min. Xong vòng trong mới đổi chỗ một lần.

temp trong C++ là biến tạm để đổi hai giá trị.

procedure SelectionSort(a[0..n−1])   // bắt đầu sắp xếp chọn
  for i ← 0 to n−2 do                // vòng ngoài: vị trí cần đặt min
    min ← i                          // tạm coi a[i] là nhỏ nhất
    for j ← i+1 to n−1 do            // vòng trong: tìm min thật
      if a[j] < a[min] then min ← j  // gặp nhỏ hơn thì nhớ vị trí
    end for
    swap a[i] with a[min]            // đưa min về đúng chỗ
  end for
end procedure
void selectionSort(int a[], int n) {     // hàm C++
  for (int i = 0; i < n - 1; i++) {      // i từ 0 đến n−2
    int min = i;                         // giả sử min ở vị trí i
    for (int j = i + 1; j < n; j++) {    // tìm phần tử nhỏ hơn
      if (a[j] < a[min]) min = j;        // cập nhật vị trí min
    }
    int temp = a[i]; a[i] = a[min]; a[min] = temp;  // đổi chỗ 1 lần
  }
}

Mô hình ví dụ – Sinh viên

Sau Selection Sort theo điểm: Lê Văn C 6.8 → Nguyễn Văn A 7.5 → Trần Thị B 8.2 → Phạm Thị D 9.0.

Ưu điểm

Dễ hiểu, dễ cài đặt. Đổi chỗ rất ít, tối đa n trừ 1. Không cần bộ nhớ phụ. Hành vi dự đoán được.

Nhược điểm

Luôn O(n²), kể cả khi dữ liệu gần sắp. Không ổn định. Không dừng sớm. Ít dùng trong thư viện chuẩn.

Kết luận

Selection Sort đơn giản, đổi chỗ ít, phù hợp học cơ bản và dữ liệu nhỏ. Nhược điểm chính là chậm vì O(n²). Nhóm em xin cảm ơn thầy cô và các bạn.
