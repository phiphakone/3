Selection Sort (Sắp xếp chọn)

Bài thuyết trình nhóm – khoảng 10 người lần lượt trình bày

Từ ý tưởng

Trong mỗi bước, tìm phần tử nhỏ nhất trong đoạn chưa sắp, rồi đưa về đúng vị trí đầu. Số lần đổi chỗ tối đa n − 1 lần.

Khi nào nên dùng / không nên dùng

Phù hợp mảng nhỏ. Không nên dùng dữ liệu lớn vì O(n²) — số so sánh khoảng n × n. Ví dụ 100 phần tử ≈ 10.000 lần so sánh.

✓ Phù hợp khi

  • Mảng nhỏ (n < 50)
  • Chi phí swap cao
  • Giảng dạy cơ bản

✗ Không phù hợp khi

  • Dữ liệu lớn
  • Cần ổn định

Thuật toán chi tiết

Bước 1: i = 0.

Bước 2: min = i.

Bước 3: Duyệt j từ i+1 đến n−1, cập nhật min khi gặp nhỏ hơn.

Bước 4: Đổi chỗ a[i] với a[min].

Sơ đồ minh họa từng bước

Mảng 64, 25, 12, 22, 11. Tìm min rồi đổi về đầu từng vòng.

Ban đầu

Mã giả & Cài đặt C++

procedure SelectionSort(a[0..n−1])   // bắt đầu sắp xếp chọn
  for i ← 0 to n−2 do                // vòng ngoài: vị trí cần đặt min
    min ← i                          // tạm coi a[i] là nhỏ nhất
    for j ← i+1 to n−1 do            // vòng trong: tìm min thật
      if a[j] < a[min] then min ← j  // gặp nhỏ hơn thì nhớ vị trí
    end for                          // đã tìm xong min
    swap a[i] with a[min]            // đưa min về đúng chỗ
  end for
end procedure
void selectionSort(int a[], int n) {     // hàm C++
  for (int i = 0; i < n - 1; i++) {      // i từ 0 đến n−2
    int min = i;                         // giả sử min ở vị trí i
    for (int j = i + 1; j < n; j++) {    // tìm phần tử nhỏ hơn
      if (a[j] < a[min]) min = j;        // cập nhật vị trí min
    }
    int temp = a[i]; a[i] = a[min]; a[min] = temp;  // đổi chỗ 1 lần
  }
}
procedure / hàm: bắt đầu Selection Sort
for i: mỗi vòng chốt 1 vị trí phía trước
min ← i: tạm coi a[i] là nhỏ nhất
for j: duyệt phần còn lại để tìm min thật
if a[j] < a[min]: gặp nhỏ hơn thì nhớ vị trí j
swap / temp: đổi chỗ một lần bằng biến tạm

Mô hình ví dụ – Sinh viên

Sau Selection Sort: Lê Văn C 6.8 → Nguyễn Văn A 7.5 → Trần Thị B 8.2 → Phạm Thị D 9.0.

Ưu điểm

Dễ hiểu, đổi chỗ ít (≤ n−1), sắp tại chỗ.

Nhược điểm

Luôn O(n²), không ổn định, không dừng sớm.

Kết luận

Selection Sort đơn giản, đổi chỗ ít, nhưng chậm vì O(n²). Nhóm em xin cảm ơn thầy cô và các bạn.
